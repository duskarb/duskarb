# Namkyu Yeo — 여남규

Designer working across **interfaces**, **installations**, and **graphic systems**.  
KAIST Industrial Design · Visual Instruments Lab (`vv`) · Daejeon & Seoul.

---

Interested in the rules, measurements, and assumptions embedded in technologies that pass for neutral.

Attention becomes data. Language becomes structure. Interfaces become systems of judgment.

The recurring question is not what a system does —  
but what it makes possible, and for whom.
